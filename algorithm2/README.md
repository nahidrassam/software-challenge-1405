## گروه‌بندی کلمات هم‌حرف (۷۵ امتیاز)

تابعی بنویسید که یک آرایه از کلمات را دریافت کند و کلمات را طوری در گروه‌ها قرار دهد که هر گروه شامل کلماتی باشد که با جابه‌جا کردن حروفشان می‌توان یکی را به دیگری تبدیل کرد (anagram).

<br/>
<br/>

### مثال‌ها

نمونه‌ی اول:

```
Input: words = ["eat", "tea", "tan", "ate", "nat", "bat"]

Output: [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

<br/>

نمونه‌ی دوم:

```
Input: words = ["listen", "silent", "hello", "world"]

Output: [["listen", "silent"], ["hello"], ["world"]]
```

<br/>

نمونه‌ی سوم:

```
Input: words = [""]

Output: [[""]]
```

<br/>
<br/>

### محدودیت‌ها:

<div dir="rtl">
<li><span dir="ltr">1 <= words.length <= 10000</span></li>
<li><span dir="ltr">0 <= words[i].length <= 100</span></li>
<li>کلمات فقط شامل حروف کوچک انگلیسی هستند.</li>
<li>ترتیب گروه‌ها در خروجی مهم نیست.</li>
</div>

<br/>

### نکته

سعی کنید حداقل دو راه‌حل مختلف برای این مسئله در نظر بگیرید (مثلاً یکی با مرتب‌سازی حروف و یکی با شمارش حروف) و در توضیحاتتون بنویسید کدوم راه‌حل توی چه شرایطی سریع‌تره و چرا. لازم نیست هر دو رو کد بزنید، همون یکی که فکر می‌کنید بهتره کافیه.
