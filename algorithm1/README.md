## پرانتزهای معتبر (۷۵ امتیاز)

تابعی بنویسید که یک رشته دریافت کند و بررسی کند که آیا پرانتزها، براکت‌ها و آکولادهای داخل آن معتبر و درست تو در تو قرار گرفته‌اند یا نه.

رشته می‌تواند شامل حروف، اعداد و کاراکترهای دیگر باشد که باید نادیده گرفته شوند. تنها کاراکترهای `(`, `)`, `[`, `]`, `{`, `}` مهم هستند.

یک رشته وقتی معتبر است که:

- هر براکت باز، با یک براکت بسته‌ی هم‌نوع خودش بسته شود.
- براکت‌ها به ترتیب درست بسته شوند.

<br/>
<br/>

### مثال‌ها

نمونه‌ی اول:

```
Input: s = "a(b)c[d]e"

Output: true
```

<br/>

نمونه‌ی دوم:

```
Input: s = "f(x) = {a[i] + b[i]}"

Output: true
```

<br/>

نمونه‌ی سوم:

```
Input: s = "([)]"

Output: false
```

توضیح: پرانتزها و براکت‌ها به ترتیب درست بسته نشده‌اند.

<br/>

نمونه‌ی چهارم:

```
Input: s = "sum(a, b"

Output: false
```

توضیح: پرانتز باز شده ولی بسته نشده است.

<br/>
<br/>

### محدودیت‌ها:

<div dir="rtl">
<li><span dir="ltr">1 <= s.length <= 10000</span></li>
<li>رشته می‌تواند شامل هر کاراکتر ASCII باشد.</li>
<li>پیاده‌سازی باید از لحاظ زمانی کارا باشد.</li>
</div>

<br/>

### نکته

علاوه بر کد، توضیح بدید چرا روش انتخابی‌تون رو انتخاب کردید. اگه راه‌حل دیگه‌ای هم به ذهنتون رسیده بود، یک مقایسه‌ی کوتاه بین دو راه‌حل بنویسید (سرعت، حافظه، خوانایی).
